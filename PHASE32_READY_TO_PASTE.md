# Phase 32 — Ready to Paste

1. Back up the current project or commit it to source control.
2. Extract `PRISM_Publications_Phase32_ReadyToPaste.zip` directly into the `ProjectManagement` root.
3. Preserve the directory structure and replace matching files.
4. No EF Core migration is required.
5. Run `.\tools\Test-PrismPublicationsPhase32.ps1`.
6. Build the solution and run the Compendium tests.
7. Open the Compendium, re-review affected projects, Preview PDF, then Download PDF.

Phase 32 intentionally does not redesign the workflow or add more project-layout buttons. It makes the existing five modes more adaptive and truthful.
