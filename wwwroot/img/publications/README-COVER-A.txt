PRISM COVER A — OPTIONAL INSTITUTIONAL ARTWORK
==============================================

Cover A now supports an organisation-approved institutional artwork asset.

Place ONE of the following files in this folder:
  cover-a-institutional.jpg
  cover-a-institutional.png
  cover-a-institutional.webp

Recommended source:
  - landscape artwork, approximately 16:9
  - at least 2000 px wide
  - no embedded brochure title/date/classification text
  - artwork only; PRISM overlays the live title, edition, logos, strapline and marking

If no approved artwork is present, Cover A automatically uses the selected project-photo
montage. Brochure generation therefore never depends on this optional asset.
