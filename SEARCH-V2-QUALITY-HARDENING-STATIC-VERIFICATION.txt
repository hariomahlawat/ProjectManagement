Implemented hardening gates
---------------------------
- Unicode dash/underscore query normalization.
- Cross-punctuation highlight terms.
- Exact/prefix identifier consistency between suggestions and committed search.
- `title_phrase` relevance channel.
- Exact/prefix alias consistency between suggestions and committed search.
- `title_token_prefix` committed-search channel using the same final-token prefix semantics as autocomplete.
- `title_fuzzy` committed-search channel so fuzzy autocomplete candidates remain discoverable.
- Strong title/identifier/alias intent tiered ahead of broad structured/body matching.
- Narrative/English matches tiered below structured matches.
- `searchTextQuality` projection metadata and narrative rank weighting.
- Low-quality snippet suppression and display sanitation.
- ProjectionVersion 4 atomic rebuild boundary; no new EF migration.
- Six-result autocomplete cap plus existing “See all results”.
- Trackers -> Records display mapping without URL/filter key changes.
- All-result count and neutral legacy partial heading.
- Results search/tabs sticky header clears the PRISM application header (52 px desktop / 50 px small screens fallback).
- Admin Search Index Ranking Inspector using the real V2 ranker under the current authorization context, exposing rank, matched field, tier, channels and RRF score without ordinary search-query analytics writes.
- Optional SearchResult MatchTier/MatchChannels diagnostics; legacy adapted results remain compatible through optional fields.
