PRISM Standard Briefing — Final Visual Polish
================================================

Purpose
-------
This package completes the agreed refinements to the Standard PRISM Briefing
PowerPoint design after the maroon-header and unified bottom-strip changes.

Implemented changes
-------------------
1. Long Present Status content now remains readable:
   - Short stage/status combinations stay on one line.
   - Longer combinations place the authoritative present stage on the first
     line and the exact external status on the second line.
   - No status, qualifier, remark or interpretation is generated by PRISM.
   - Missing external status remains silently omitted.

2. Graphite Dark header refinement:
   - The top institutional rule now uses a restrained muted burgundy (#8A3042)
     rather than the brighter maroon-red used previously.
   - The Deck Settings theme preview uses the same colour.

3. Graphite Dark branding refinement:
   - Bright white logo backing tiles are replaced by compact dark-neutral
     plates (#242A34) with a subtle border (#4A5260).
   - Logo plates and image boxes are optically reduced on cover and standard
     briefing slides while preserving title-safe areas.
   - Editorial Light branding is unchanged.
   - Project Update Sheet styling is unchanged.

Files to replace
----------------
Copy the included files over the matching project-relative paths:

- Services/ProjectBriefings/Presentation/ProjectBriefingSlideComposer.cs
- Services/ProjectBriefings/Presentation/ProjectBriefingThemeDefinition.cs
- wwwroot/css/pages/project-briefing-decks.css
- ProjectManagement.Tests/ProjectBriefings/ProjectBriefingSlideComposerTests.cs
- ProjectManagement.Tests/ProjectBriefings/ProjectBriefingContractTests.cs

Deployment
----------
1. Back up the existing files or commit the current state.
2. Replace the five files listed above.
3. Clean and rebuild the solution in Visual Studio.
4. Run the ProjectBriefings test suite.
5. Generate one Editorial Light and one Graphite Dark deck and verify:
   - long combined status uses two readable lines;
   - no inferred status text appears;
   - the dark header uses muted burgundy;
   - dark logo plates are compact and neutral.

Database
--------
No database migration is required.

Baseline
--------
These files include and supersede the earlier Standard Briefing packages for:
photo-layout variants, consolidated Present Status/cost strip, and maroon
header/subheading removal.
