PRISM ERP - Notebook bidirectional drag-and-drop fix
====================================================

Replace these three files in the project with the files in this package:

1. wwwroot/js/notebook/notebook-drag-order.js
2. wwwroot/js/notebook/notebook-drag-order.test.js
3. wwwroot/js/notebook/notebook-direct-drag-contract.test.js

No Razor, CSS, controller, service, database, or migration change is required.

After replacement, rebuild the project normally. ProjectManagement.csproj already runs
"npm run build:notebook" before Build/Publish when Notebook frontend inputs change, so
wwwroot/dist/notebook-index.bundle.js, its source map, and notebook-manifest.json will be
regenerated by the existing build pipeline.

Recommended verification:
  npm test
  npm run build:notebook
  dotnet build

Functional acceptance checks:
- Drag a note left and right within the same visual row.
- Drag a note upward and downward across masonry rows.
- Move a note repeatedly in both directions without dropping between movements.
- Move the Conference Directions system card in both directions.
- With a shared/read-only note present, move an owned note to the end and confirm the
  shared card remains outside the reorderable owned-card region.
- Reload the page and confirm the saved order persists.
